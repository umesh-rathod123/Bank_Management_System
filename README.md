# Bank Management System

A Python-based command-line banking application that demonstrates basic account and transaction management with Excel file storage.

## Features

- Create a bank account
- Generate an account number
- Deposit money
- Withdraw money
- Check account balance
- Verify a user PIN
- Validate transaction amounts and available balance
- Save account records in an Excel workbook

## Tech Stack

- **Language:** Python 3
- **Data storage:** Excel
- **Excel library:** OpenPyXL

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/umesh-rathod123/Bank_Management_System.git
cd Bank_Management_System
```

### 2. Install the dependency

```bash
python -m pip install openpyxl
```

### 3. Run the application

Run the Python entry-point file included in the repository, for example:

```bash
python main.py
```

If the entry-point file has a different name in your checkout, use that filename instead.

## Data and Security

The application uses an Excel workbook for account data. Do not upload real customer information, account details, or PINs to a public repository. This project is intended as a learning demonstration and is not a production banking system.
